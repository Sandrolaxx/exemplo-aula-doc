# exemplo-aula-doc
Exemplo de documentação com MkDocs

## Ambiente Virtual

* `python -m venv .venv`
* `source .venv/bin/activate`
* `pip install -r requirements.txt`

## Projeto com MkDocs

* `mkdocs new .`
* `echo > docs/index.md` Apenas para deixar o arquivo em branco
* `mkdocs gh-deploy` Publicação do Site
